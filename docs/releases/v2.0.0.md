# Unruggable App v2.0.0 — MLH Hardware Wallet Support

Version 2 adds first-class support for the finalized MLH dual-element hardware wallet while preserving First Edition, legacy PIN/OTP, and Ledger code paths.

## Highlights

- Detects the MLH/CurrentV2 protocol and validates real 32-byte Solana public keys.
- Supports computer-first PIN entry, safe first-time key generation, on-device receive QR, typed firmware errors, and the MLH signing limit.
- Keeps First Edition transaction approval as a single button press and uses press-and-hold guidance for MLH transaction review.
- Adds Windows COM-port, USB Hardware ID, no-COM, busy-port, and manual-port diagnostics.
- Fixes stale hardware state after sends and makes pre-approval cancellation safely terminate the USB session.
- Routes swaps through the managed API, isolates provider failures, and supports oversized MLH swaps through bounded Solana v1 transactions.
- Repairs native stake discovery/balances and enforces a minimum stake of 1 SOL.
- Bundles desktop CSS and essential images locally so the app no longer depends on a mutable CDN branch.

## Downloads

- macOS Apple Silicon: `unruggable.dmg`
- Windows x86-64: `unruggable-app-windows.zip`
- Linux x86-64: `unruggable-linux.zip`
- Each package has a matching `.sha256` checksum file.

The Windows package includes `WINDOWS_USB_SUPPORT.md`. Install only the USB driver matching the Hardware ID reported by Windows or the app diagnostics.

## Compatibility

- Finalized MLH firmware: `firmware-v0.3.3-mlh-2026`
- First Edition Unruggable hardware wallets
- Legacy NONE/PIN/OTP protocol variants
- Ledger support retained

Firmware and desktop-app versions are independent. Existing hardware does not need a firmware update to use this desktop release.
